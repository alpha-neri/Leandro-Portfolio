Project Overview

Galactic Pulse was conceptualized as a sensory experience that bridges the gap between traditional gaming and generative art. The project focuses on "Pulse" logic—where visual elements react in real-time to user input and background frequencies.

Developed during an intensive hackathon sprint, the project leveraged AI-assisted development to optimize particle physics, ensuring smooth 60FPS performance even on mobile browsers.

Real-time Physics

Engineered a custom JS engine for handling thousands of concurrent particles.

Audio Reactive

Visuals that expand and contract based on musical frequency and intensity.
